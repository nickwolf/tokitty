python-xlib

python-xlib is the X11 client library pystray uses for the tray icon on Linux. It is bundled, unmodified, only in the Linux build of this application.

python-xlib is a pure Python package and ships here as plain .py files, not inside the compiled application archive: the Xlib folder in _internal beside the executable. You can replace that folder with any other version of python-xlib, including one you have modified yourself.
