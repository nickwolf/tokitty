pystray

pystray provides the system tray icon in Tokitty's Tk mode. It is bundled with this application as an unmodified Python package.

pystray is a pure Python package and ships here as plain .py files, not inside the compiled application archive: the pystray folder in _internal beside the executable on Windows and Linux, and in Tokitty.app/Contents/Resources/ on macOS. You can replace that folder with any other version of pystray, including one you have modified yourself.
