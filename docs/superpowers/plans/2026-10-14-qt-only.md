## Slice 1: renderer (spec decision 3)

Files: `tokitty/streamdock/render.py`, `tokitty/streamdock/fonts/` (Aileron TTF and notice), an extraction script under `scripts/` if the TTF comes from Pillow, `tests/test_streamdock_render.py`, `tests/test_streamdock_keyimages.py`, and any other test whose only Pillow use is the renderer. Runs in parallel with slice 2.

Done when: `render.py` imports no Pillow; the API and memoisation are unchanged; the font is registered by a `register_font()` that `run_qt` will call (slice 3 wires the call); rendering without registration raises; the tests are `qt`-marked and cover size, determinism, truncation, the loaded font, a render on a worker thread, and a render through a real `/plan` request; `QFontDatabase.supportsThreadedFontRendering()` is asserted in a test so the `qt` CI job reports it on all three systems.

Done when: every GUI launch runs `run_qt`; nothing reads `TOKITTY_QT` (outside `frozen.py` and `freeze/`, which slice 4 owns); no module under `tokitty/` imports tkinter; the isolation test imports every module under `tokitty/` with tkinter, `_tkinter`, pystray, AppKit, Foundation, objc and Xlib blocked (PIL is added in slice 4, after slice 1); both test runs pass, with the deleted test count reported.
