## Slice 2: Qt dialog and handover host (after 1)

Files: new `tokitty/qt/update_dialog.py`, `tokitty/qt/update_host.py`, `tokitty/qt/host.py`, new `tests/qt/test_update_dialog.py`, `tests/qt/test_update_host.py`, `tests/test_toolkit_isolation.py`.

1. `qt/update_dialog.py`: `QtUpdateDialog(QWidget)` with `open(host, release, running, controller, open_url=webbrowser.open)` as a classmethod and a module- or class-level single instance, as `UpdateDialog.open` has. Parentless, title "Update Tokitty", fixed size after layout, the #112 kit's style sheet and colours (`tokitty/qt/kit.py`, `settings_style`), info label, note label with word wrap at `WRAP_PX`, a button row rebuilt on each `show(note, buttons)`. `close()` (the renderer's) closes the window. `closeEvent` ignores the event unless the flow allows it (`flow.close_requested()` decides; when it closes, the event is accepted), and on an accepted close calls `host.forget_window(self)` and clears the instance. `host.register_window(self)` before the first `show()`. Reopening raises and activates the existing one. Test-facing helpers with the Tk names: `note`, `button_labels()`, `invoke(label)`, `alive`.
2. `qt/update_host.py`: `QtUpdateHost(app, host, lock, state_dir, backend, *, quiet=False, warn=None)` with `hide`, `restore`, `finish`, `notice` and a `hidden` property, per spec decision 3. `hide` walks `QApplication.topLevelWidgets()`, skips invisible ones and `qt.deck_views.QtView` instances, remembers the visible ones that `host` has registered plus the widget itself, hides all of them, then `lock.release()`. `restore` calls `update_controller.reclaim(...)` first (it raises `LockAcquisitionError` before anything is shown, as `TkHost.restore` does), then shows the remembered windows, re-applies stacking through the host's existing `_apply_stacking` path (add a small public `restack(window)` to `QtHost` rather than calling the private method), and clears `hidden`. `finish` does `QTimer.singleShot(0, app.quit)` and is safe twice. `notice(text)` returns when quiet, else `QTimer.singleShot(0, lambda: host.warn("Tokitty", text))`.
3. `qt/host.py`: add `on_install_update = None` next to the four update seams and update the module docstring and the "#114, #113" comment so they say the update seams are set by `run_qt`.
4. Tests (`tests/qt/`): the spec's Dialog and Host bullets. For the modal case, open a `QMessageBox.warning` from a `QTimer` and call `hide` from a second timer inside its loop; assert it returned `NoButton` and stays hidden after `restore`. Use a fake lock (records acquire and release; can be told to fail) and patch `update_controller.reclaim` where it would touch the state dir, or give it a `tmp_path` state dir and a `None` backend.
5. Isolation: add `tokitty.qt.update_dialog` and `tokitty.qt.update_host` to `_QT_MODULES`.
